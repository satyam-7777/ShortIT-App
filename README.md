# ShortIT – URL Shortener

ShortIT is a URL shortening application that allows users to convert long URLs into short, shareable links.

The project is built with React for the frontend and Node.js with Express.js for the backend.

Render Live Project Url : https://shortit-app.onrender.com/

## Features

- Shorten long URLs into compact links
- Easily share shortened URLs
- Redirect users from short links to their original URLs
- Simple and responsive user interface

## Tech Stack

### Frontend

- React
- JavaScript
- CSS

### Backend

- Node.js
- Express.js
- REST APIs

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Git

### Clone the Repository

```bash
git clone <repository-url>
cd ShortIT-App
```

### Setup Frontend

```bash
cd client
npm install
npm start
```

### Setup Backend

Open another terminal:

```bash
npm install
npm start
```

The frontend and backend will start according to the ports configured in your project.

## Usage

1. Open the ShortIT application in your browser.
2. Enter the long URL you want to shorten.
3. Generate the shortened URL.
4. Copy and share the shortened link.
5. When someone opens the shortened link, they are redirected to the original URL.
